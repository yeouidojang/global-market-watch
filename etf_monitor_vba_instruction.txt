기존 것을 참고해서 새로운 vba 자동화 작성.
1. date A열 15행부터 inSector B6에 넣어서 루프 돌리는 것은 동일(루프문1). inSector!B6 값 base_date에 할당해서 저장
2. 그 다음 inSector 하이퍼링크 실행
3. 14행부터 G열 주식 or 빈칸, H열 국내, K열 일반 or 레버리지 or 인버스 1X or 인버스 2X 필터링 후 M열~Q열 평균이 1,000 이상인 종목 필터링해서 A열, B열 데이터를 Screen A14, B14 부터 vertical하게 값 붙여넣기. A, B열 데이터 etf_universe 값에 할당
4. Screen 하이퍼링크 실행. '<- 2번 작업과 매커니즘 동일
5. Screen 9행부터 끝까지 etf sheet에 값붙여넣기
6. etf sheet 6행부터 AB~AF열 데이터를 AG데이터로 나누어 AH~AL열에 삽입. header="num_cu", period= AB~AF열 2행 데이터
7. etf sheet 엑셀 파일명_sheet명_"base_date".csv로 저장
8. inSector sheet E4~I4 값 -> run_date로 할당. bd sheet A열에 해당하는 값 있는 경우에만. 아래 파이프라인 루프문 실행(루프문2). 루프문2 첫간계 실행 전 run sheet 8열부터 초기화. inSector sheet E4~I4 값 run sheet B4에 값 붙여넣기
9. etf_universe에 해당하는 값 8,9열에 horizontal하게 값복사넣기. 단! 5행 간격으로 A, F, K, ...  10행에는 etf_universe 갯수 만큼 코드, 구성종목, 주식수(계약수), 금액, 금액기준 구성비중(%) 반복해서 삽입
10. run sheet 하이퍼링크 실행하고, run sheet 엑셀 파일명_sheet명_"base_date"_"run_date".csv로 저장.
11. 루프문 1로 돌아와서 루프 실행.
*** 참고사항 값붙여넣기 하는 구간은 무조건 해당 부분 초기화하고 값붙여넣기 하는거로. 데이터 개수가 매번 다를 수 있는데 기존 데이터가 남아있어서 오염시키는 행위 방지하기 위함
